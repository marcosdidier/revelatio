# Dossier — n8n

> Brief-listed tool · Will test hands-on in **Epic 5.5**. Doubles as the **Diferencial: Fluxo Alternativo** (Epic 7.2).

## What it is
Open-source workflow automation platform. Same role as Make/Zapier but **self-hostable** via Docker / npx in 1 command. Visual editor + JS code nodes for custom logic. Native nodes for OpenAI, Anthropic, Google Sheets, Postgres, HTTP, file-watchers. Cloud-managed version also available (n8n.cloud) for those who want it.

## Where it fits in our pipeline
- **Extractor**: no — it orchestrates other tools' extractor APIs.
- **Orchestrator**: ✅ ✅ — primary candidate for the no-code production flow.
- **Bridge to non-engineers**: a workflow in n8n is *visible*. The legal-ops lead can see "PDF in → call API → row out" without reading Python. That's a maintenance superpower.
- **Alternative flow**: in the relatório (Epic 7.2) we propose n8n as the no-code path for teams that don't have a Python developer.

## Hands-on plan (Epic 5.5)
1. Run n8n locally: `npx n8n` (or `docker run -p 5678:5678 n8nio/n8n`).
2. Build a workflow:
   - Trigger: Manual file upload (or watch folder for production)
   - Step 1: Read binary file
   - Step 2: HTTP node calling Anthropic Claude API with PDF body
   - Step 3: JSON parser → schema validation
   - Step 4: Google Sheets append row
   - Step 5: On error, send to a "review queue" sheet
3. Run on the example PDF; capture workflow JSON export, screenshots of the canvas, and the resulting sheet row.
4. Document scaling notes: how many concurrent executions, queue mode, etc.

## LGPD / data-residency
- **Self-hosted on firm's infra**: data **never leaves the firm's network** (except the leg that calls the chosen Doc-AI/LLM API, which we can also swap to a local OSS extractor like Docling for full air-gap).
- **Strongest LGPD posture in this entire dossier set** (alongside Tabula and Docling).
- Audit logs by default; integrates with on-prem identity providers.

## Cost class
- Self-host: hosting cost only ($5–20/mo for a small VPS); software is free under fair-code license.
- n8n.cloud: $20–50/mo paid tiers
- 💲 (self-host)

## Fit verdict
**✅ Recommended** — primary orchestrator for the production flow AND the alternative no-code flow we propose for the legal-ops team. The self-host LGPD win + visual editor + free-as-in-libre licensing is hard to beat for a Brazilian law firm.

## Production patterns to highlight
- **Queue mode** (n8n + Redis): for >100 concurrent PDFs, keeps memory usage flat
- **Webhook trigger**: integrate with a "drop PDF here" portal so cobrança team can self-serve
- **Error workflow**: any failure routes to a "needs human review" sheet → ties directly into our HITL story (`07_recommendation/playbook.md`)
- **Versioning**: workflows are JSON; commit them to git for change control
